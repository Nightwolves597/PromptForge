        Terms

        Last updated October 31, 2026

        What PromptForge is

        PromptForge is a student project. It uses AI to rewrite prompts so they cost fewer tokens. It is provided as it is, with no promise that it is available, accurate or right for your use.

        Check every result

        A shortened prompt can lose or change meaning. The server checks that numbers, links, quoted text and code are still there. It cannot check that the meaning is the same. Read each result before you use it. You are responsible for how you use it.

        What you send

        You keep the rights to what you paste. Only send text you are allowed to share. Do not send passwords, API keys, private data about other people, or anything unlawful.

        Fair use

        Do not try to overload, break into or scrape the service. It depends on the limits of Google's Gemini API, so it can slow down, switch models or stop without notice.

        Changes

        These terms can change. The date at the top shows the latest version. To the extent the law allows, the person running this site is not liable for losses from using it.

        Privacy

        Last updated October 31, 2026

        Where your text goes

        Prompts you shorten, and notes you enter in Prompt Maker, are sent from PromptForge's server to Google's Gemini API, which writes the result. If the server uses Google's free tier, Google may use what it receives to improve its products. Do not send anything confidential.

        Token counts

        Tokens are counted on the server with the OpenAI tokenizer library, so the count does not send your text to OpenAI.

        What is saved

        Each shortened prompt is saved in the app's database with its mode and token counts, so the History panel and the Stats page can show it. Favourites and tags are saved with the run. Turn off Save new runs in the panel and new runs are not saved. Clear history deletes every saved run. Whoever runs the server can read that database.

        Test it live sends your original and your shortened prompt to Gemini as two ordinary questions, then sends both answers in a third request so they can be compared.

        Handoff reads the files you add inside your browser and sends them to this server. Plain code on the server finds the endpoints, fields, file names and variable names, and masks anything that looks like a key, token or password. Gemini then gets only your notes, a list of file and function names and what the code found, never your source code. Only the finished prompt is shown to you. The files themselves are not saved, but a line about each run (your notes and the token counts) is kept in this browser's history.

        Your browser keeps a draft of what you typed and your model choice, so they are still there when you come back. This stays in your browser.

        What is not collected

        There are no accounts, no ads, no analytics and no tracking cookies. The page loads its fonts from Google Fonts, which can see your IP address when it does.
